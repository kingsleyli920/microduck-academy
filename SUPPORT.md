# Support / 使用帮助

Microduck Academy is an early open-source preview maintained by the community.

- For reproducible classroom or simulator problems, open a **Bug report** and include the level, browser, operating system, Node.js version, and reproduction steps.
- For lesson or API proposals, open a **Lesson or API idea** and describe the runnable evidence that should prove it works.
- For security vulnerabilities, use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
- For questions about the official simulator, training stack, or physical robot, check the upstream projects linked in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Please do not attach secrets, private learning profiles, proprietary policies, or generated simulator assets to public issues.

Microduck Academy 是社区维护的早期开源预览版本。

- 可以复现的课堂或模拟器问题，请提交 **Bug report**，并写明关卡、浏览器、操作系统、Node.js 版本和复现步骤。
- 新关卡或 API 建议，请提交 **Lesson or API idea**，并说明什么可运行结果能够证明它有效。
- 安全漏洞请按照 [SECURITY.md](SECURITY.md) 使用 GitHub 私密漏洞报告。
- 官方模拟器、训练栈或实体机器人问题，请先查看 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 中的上游项目。
